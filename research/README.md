# Protocol data

- `k636-keymap.json`: keyboard layout and LED slots, embedded by the build.
- `k636-protocol.md`: keyboard report format and interface selection.
- `openrgb-device-0.bin` and `openrgb-device-1.bin`: OpenRGB protocol 4 test fixtures for motherboard and mouse descriptors. Serial numbers and device-instance paths use synthetic values; these are not runtime device addresses.
